# RitmDojo

Ритм-тренажёр для гитары: рисунки (четверти, восьмые, шестнадцатые, триоли, ноты с точкой, синкопа) с голосовым счётом «раз и два и», анимацией ноги и общим прогрессом. Игровой режим оценивает попадание по звуку гитары с аудиоинтерфейса: уровни, звёзды, счёт, статистика тайминга.

Работает как PWA: ставится как приложение и после первого запуска работает без сети.

## Локальный запуск
```
python3 -m http.server 8000
```
Откройте http://localhost:8000. Микрофон и вход интерфейса работают только на localhost и по https.

## Файлы
- `index.html`: всё приложение вместе с голосом
- `manifest.json`, `sw.js`, иконки: PWA и офлайн-кэш
- `.nojekyll`: отключает обработку Jekyll на GitHub Pages

## Обновление
Измените `index.html`, увеличьте `VERSION` в `sw.js` и закоммитьте.
