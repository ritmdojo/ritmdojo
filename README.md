# RitmDojo

Ритм-тренажёр для гитары: рисунки (четверти, восьмые, шестнадцатые, триоли, ноты с точкой, синкопа) с голосовым счётом «раз и два и», пиксельным метрономом в шапке и общим прогрессом. Счёт перед стартом бывает на один или два такта: «раз, два, три, четыре» или «раз — два —», а затем полный счёт. Игровой режим оценивает попадание по звуку гитары с аудиоинтерфейса: живой счёт, точность и серия на вкладке «Игра», итог, статистика тайминга и таблица рекордов — на вкладке «Счёт». Настройки и подсказки вынесены на отдельные экраны.

Работает как PWA: ставится как приложение и после первого запуска работает без сети.

## Локальный запуск
```
python3 -m http.server 8000
```
Откройте http://localhost:8000. Микрофон и вход интерфейса работают только на localhost и по https.

## Файлы
- `index.html`: разметка, стили и скрипт приложения
- `voice/`: пять MP3 для голосового счёта, загружаются по ссылке
- `manifest.json`, `sw.js`, иконки: PWA и офлайн-кэш
- `.nojekyll`: отключает обработку Jekyll на GitHub Pages
- `tests/`, `playwright.config.js`, `package.json`: Playwright-тесты (только для разработки)

## Тесты
```
npm install
npx playwright install chromium
npm test
```
Playwright сам поднимает `python3 -m http.server 4173`. Микрофон подменяется фейковым устройством, поэтому тесты не проверяют реальный звук. Подробности и ручной чек-лист — в `AGENTS.md`.

## Обновление
Измените `index.html` или файлы в `voice/`, увеличьте `VERSION` в `sw.js`, прогоните `npm test` и закоммитьте.
